Verify Your Athena UI Download

Use a SHA-256 checksum to compare your downloaded installer with the exact file published for that release. Each installer version and filename needs its own checksum.

Published Checksums

Pending publication: No installer checksums have been supplied for this page yet. Do not treat a file as verified until its exact filename, version, and SHA-256 value are published here. We will add release entries when the corresponding installers are finalized.

Browse the official release history for published installers and release notes. If your version is not listed with a checksum here, ask us for its verification details.

Calculate SHA-256 on Windows

  1. Download an installer from the official release location. Do not run it yet.
  2. Open PowerShell and run the command below, replacing the example path with the actual downloaded filename.
  3. Compare the complete value in the Hash column with the published SHA-256 for that exact filename and version. Letter case does not matter; every hexadecimal digit must match.
  4. If the values differ, do not run the file. Delete that download, download again from the official source, and contact us if the mismatch persists.
Get-FileHash -Algorithm SHA256 -LiteralPath "C:\Users\YourName\Downloads\EXACT-INSTALLER-FILENAME.exe"

A checksum verifies a match, not safety. It does not identify the publisher, scan for malware, or protect you if both the installer and the published checksum are compromised. Keep Windows protections enabled and consider scanning the file with your security software.

Code Signing and Windows Warnings

JID Holdings LLC is applying for app-signing credentials. Early Athena UI installers may be released before signing is available. Windows may display an unknown-publisher warning or block an unsigned installer. SmartScreen and Smart App Control are separate protections; behavior varies by system.

We do not recommend turning off Windows security protections. If installation is blocked, contact us with the exact warning or wait for a signed release. Code signing helps identify a publisher, but does not guarantee safety or the absence of warnings.

When reporting a warning through our bug report form, include the installer filename, version, Windows version, and warning text. Never send API keys, passwords, or private records.
