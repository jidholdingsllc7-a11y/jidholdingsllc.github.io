Meet Synergy: Two Coding Models. One Collaborative Workflow.

Synergy isn’t another character. It pairs two coding models you choose—Code Model A and Code Model B—to analyze your request and discuss how to accomplish it.

  • Choose your pair: Select available coding models through your configured providers.
  • Discuss the approach: Both models contribute to planning the requested program or fix.
  • Choose a writer or share the build: After agreement, a coin toss can select the code writer, or the models can jointly create a Build Map and delegate which model writes each file.

Synergy requires your own provider credentials for cloud models and access to the applicable programming tools. Both models’ usage may incur provider charges. Collaboration supports your workflow; it does not guarantee error-free code. Review and test generated changes.

Smart API Key Billing Retry

Never let a billing error disrupt your workflow. If your primary API provider runs out of funds or returns a billing error, Athena UI can automatically switch to your next available API key—so your tasks keep running smoothly.

How It Works

  • Opt-In Setting: Enable this feature in Athena UI’s settings.
  • Priority Order: Configure which API keys to try first, second, etc. (e.g., "Try Anthropic Claude first, then OpenRouter, then xAI").
  • Seamless Switching: If a billing error occurs, Athena UI checks your next API key for funds and switches automatically—no manual intervention required.
  • Customizable Fallbacks: Set as many fallback API keys as you have saved (e.g., 5 API keys = 5 fallback options).

Example Use Case

You’re running a scheduled task with Anthropic Claude, but your account runs out of funds. Athena UI detects the billing error and automatically switches to OpenRouter (your second-choice provider) to complete the task.

Set Up ElevenLabs for Voice

Want to use ElevenLabs voice features in Athena UI? You will need your own ElevenLabs account and API key. Athena UI does not include an ElevenLabs key or pay for your ElevenLabs usage.

  1. Create your account: Visit ElevenLabs, sign up, and sign in. Review the available plans, API access, and usage allowances for the voice features you intend to use.
  2. Open API Keys: In your ElevenLabs dashboard, select Developers in the sidebar, then the API Keys tab.
  3. Create a key: Create a new API key and give it a recognizable name, such as Athena UI. If access restrictions are offered, grant only the permissions needed for the voice features you use.
  4. Copy it securely: Copy the key when it is created. ElevenLabs only displays the full key at creation; keep it private and never include it in website forms, reviews, screenshots, or support messages.
  5. Enter it during Athena UI onboarding: Paste your key into the ElevenLabs API key field when setting up the Athena UI program, then complete onboarding.

ElevenLabs plan limits and charges apply separately from your Athena UI subscription. Voice requests send the text and any other content needed for the selected voice feature to ElevenLabs for processing under its policies.

Need help finding your key? Read ElevenLabs’ official API key instructions. For Athena UI setup questions, use our contact page; for an issue or tailored-version request, use our bug report and custom request form. You can also subscribe to Meera’s updates.
